01

Apa itu Kiro?

Pengenalan

Kiro adalah AI-powered development environment yang membantu developer menulis kode lebih cepat. Kiro bisa memahami konteks proyek, mengedit file, menjalankan terminal, dan berkolaborasi seperti partner coding sungguhan — bukan sekadar chatbot.

💡
Tips Praktis

Mulai sesi baru dengan menjelaskan tujuan proyekmu secara singkat. Konteks awal yang jelas membantu Kiro memberikan saran yang lebih relevan dan akurat sepanjang sesi.

Contoh penggunaan:

"Saya sedang membangun REST API dengan FastAPI. Bantu saya buat endpoint untuk autentikasi user."
02

Vibe vs Spec Session

Workflow

Vibe session cocok untuk eksplorasi cepat dan ide spontan tanpa struktur ketat — langsung koding tanpa perencanaan panjang. Spec session lebih terstruktur: Kiro membuat spec document terlebih dahulu sebelum mengimplementasi, cocok untuk fitur besar yang butuh perencanaan matang.

💡
Tips Praktis

Gunakan Spec session untuk fitur yang butuh perencanaan matang — misalnya sistem autentikasi, database schema baru, atau refactor besar. Gunakan Vibe session untuk prototyping atau perbaikan kecil.

Perbandingan:

Vibe

Spontan, cepat, eksploratif. Langsung minta Kiro implementasi tanpa dokumen rencana.

Spec

Terstruktur, ada dokumen rencana dulu. Cocok untuk fitur kompleks dan kerja tim.

03

Autopilot vs Supervised Mode

Mode Kerja

Autopilot mode: Kiro bekerja mandiri tanpa perlu konfirmasi setiap langkah, cocok untuk task rutin yang sudah kamu percayai. Supervised mode: setiap aksi perlu persetujuanmu sebelum dieksekusi, lebih aman untuk perubahan penting atau kode production.

💡
Tips Praktis

Mulai dengan Supervised mode untuk memahami cara kerja Kiro dan membangun kepercayaan, lalu beralih ke Autopilot untuk efisiensi saat kamu sudah familiar dengan pola kerjanya.

Kapan pakai masing-masing?

Autopilot → Tugas berulang, boilerplate, test generation
Supervised → Deploy, hapus file, ubah konfigurasi penting
04

Cara Pakai Context (#File, #Folder, dll.)

Konteks

Gunakan simbol # untuk menambah konteks ke percakapan dengan Kiro: #File untuk mereferensikan file spesifik, #Folder untuk seluruh direktori, #Terminal untuk output terminal terkini, #Selection untuk kode yang sedang dipilih di editor.

💡
Tips Praktis

Semakin relevan konteks yang kamu berikan, semakin akurat respons Kiro. Daripada bertanya umum, sertakan file yang relevan agar Kiro bisa melihat kode aktualmu.

Contoh penggunaan konteks:

"Ada bug di fungsi ini #File src/auth.py — tolong cek kenapa token expired terlalu cepat."
05

Hooks & Steering

Kustomisasi

Hooks memungkinkan kamu menjalankan aksi otomatis saat event terjadi (misalnya: format kode otomatis setelah file disimpan). Steering files adalah instruksi permanen di .kiro/steering/ yang selalu dibaca Kiro — cocok untuk coding conventions, tech stack preferences, atau aturan proyek timmu.

💡
Tips Praktis

Buat steering file untuk mendokumentasikan keputusan arsitektur proyekmu. Misalnya: "Gunakan TypeScript strict mode, hindari any, gunakan Zod untuk validasi." Kiro akan selalu mengikutinya.

Contoh steering file:

# .kiro/steering/conventions.md
- Gunakan Python 3.11+
- Format dengan Black, linting dengan Ruff
- Semua fungsi harus ada type hints
